# 🎙️ Voice Assistant using Python

## 📌 Project Overview
This is a Python-based Voice Assistant that listens to voice commands, understands them using speech recognition, and responds through voice output.

It can perform simple tasks such as opening websites, searching Google, telling the current time and date, and responding to basic greetings.

## ✨ Features
- Voice input using a microphone.
- Speech recognition using Google Speech Recognition.
- Text-to-speech responses.
- Open Google and YouTube.
- Open YouTube Music.
- Search Google using voice commands.
- Tell the current time and date.
- Respond to basic greetings.
- Continuous listening until the user exits.

## 🛠️ Technologies Used
- Python
- SpeechRecognition
- SoundDevice
- NumPy
- pyttsx3
- Web Browser module

## ⚙️ Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/mythili886/OIBSIP.git
```

**Step 2: Open the project folder**

```bash
cd OIBSIP/Python-Task1-VoiceAssistant
```

**Step 3: Install the required packages**

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python voice_assistant.py
```

Allow microphone access when prompted and speak after the assistant displays the listening message.

## 🗣️ Sample Voice Commands

| Voice Command | Action |
|---|---|
| Hello | Gives a greeting |
| How are you | Responds to the question |
| What is the time? | Tells the current time |
| What is today's date? | Tells the date |
| Open Google | Opens Google |
| Open YouTube | Opens YouTube |
| Play some songs | Opens YouTube Music |
| Search Python tutorials | Searches Google |
| Exit | Stops the assistant |
